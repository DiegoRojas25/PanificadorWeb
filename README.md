# 📋 Planificador de Tareas

Aplicación web para la gestión y organización de tareas personales. Permite registrar tareas indicando su título, descripción, prioridad y fecha límite, además de visualizar estadísticas y filtrar las tareas según su estado.

## 🚀 Características

- Creación de nuevas tareas.
- Asignación de prioridad: Alta, Media y Baja.
- Selección de fecha límite.
- Visualización de tareas pendientes, completadas y expiradas.
- Estadísticas generales de las tareas.
- Validación de los datos ingresados mediante JavaScript.
- Interfaz adaptable a diferentes tamaños de pantalla.

## 🛠️ Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Git y GitHub
